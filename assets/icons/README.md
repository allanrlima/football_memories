# Football Memories — SVG Icon Pack

All icons used in the Football Memories prototype.

## Lucide icons (18)
Standard 24×24, 2px stroke, currentColor — change `stroke="..."` to recolor.
Source: lucide@0.460.0 (https://lucide.dev) — ISC License.

## Custom
- crest-template.svg — placeholder team crest (gradient circle + initials)
- pitch-decoration.svg — center-circle pitch motif used on the Stats hero card
- fm-logo.svg — Football Memories app mark
